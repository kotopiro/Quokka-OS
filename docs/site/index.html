Quokka OS

ペネトレーションテスト特化型 Linux ディストリビューション。 Kali Linux / Parrot OS 系譜の「ホワイトハッカー御用達」を目指す。

  • ベース: Debian (bookworm) + Kaliリポジトリのオーバーレイ (docs/distro-decision.md)
  • デスクトップ: XFCE + LightDM、GTK/xfwm4/アイコンは Qogir-theme(GPL-3.0)採用 (docs/desktop-environment.md)
  • インストーラ: Calamares(メイン、ブランド適用済み)+ 従来型Debian Installer(上級者向け) (docs/installer.md)
  • ツール構成: Kaliのkali-tools-*を網羅的に採用 (exploitation/wireless/forensics/reverse-engineering/NIST CSF系5カテゴリ等、 主要カテゴリはほぼ全て導入済み。docs/tool-selection.md)
  • 配布形態: ISO (live-build/) + VM (vm-build/、VirtualBox/.ova・QEMU/.qcow2)
  • ビルドプロファイル: QUOKKA_PROFILE=standard|full

Quokka独自ツール

  • Quokka Fire(quokka-fire / quokka-fire-gui) — システム全体をTor経由に強制ルーティング (Parrot OSのAnonSurf相当)。GTK3の専用GUI・パネルインジケータ付き
  • Quokka Report(quokka-report) — 独自のペンテストレポート生成ツール(pandocでMarkdown→ブランド調HTML)
  • quokka-vpn-killswitch — nftablesベースのVPNキルスイッチ
  • quokka-tweaks — 設定ハブ(壁紙・効果音・USBGuard設定・ Timeshift/Synaptic/GUFW起動 等)
  • quokka-welcome / quokka-about — 初回ログイン案内・ブランド情報パネル
  • Thunar右クリックメニュー「Quokka Actions」(ハッシュ計算・evidence追加)

秘匿性・OS全体ハードニング

  • Proton VPN(公式アプリ)・Tor・カーネル/sysctlハードニング・fail2ban・ AppArmor・auditd・USBGuard・自動セキュリティアップデート
  • 正直な制約: swap無効化・journald揮発化は通常業務への支障を避けるため見送り (詳細はdocs/roadmap.md Milestone 10)

現在の状態

非常に多くの機能追加・修正を積み重ねてきており、この index.html では要約のみ記載している。正確な最新状況・各機能の「正直な制約」は 必ず roadmap.html を参照すること(Milestone 1〜30、随時更新)。

重要な未検証項目

このサンドボックスでは実際のXFCEセッション・実機起動を検証できません。 特に以下は実機/CI確認が必須です(詳細はroadmap.md参照):

  1. 実ISOビルド(GitHub Actions経由)、両プロファイルでのパッケージ差分
  2. Qogirテーマ・カーソル・パネル位置(下部)の実際の見た目
  3. quokka-fire / quokka-monitor / quokka-vpn-killswitch の実機ネットワークでの動作
  4. ディスク暗号化のデフォルト化、Forensic mode起動項目(いずれも未着手・backlog)
  5. fcitx5日本語入力・効果音パックの実機動作確認

クイックスタート

# 1. Kali GPG鍵を取得
wget https://archive.kali.org/archive-key.asc -O live-build/config/archives/kali.key.chroot

# 2. ISOビルド (standard)
cd live-build
sudo QUOKKA_PROFILE=standard lb build

# 3. ISOビルド (full)
sudo lb clean
sudo QUOKKA_PROFILE=full lb build

# 4. VMイメージビルド
cd ../vm-build
packer init .
ISO=../live-build/live-image-amd64.hybrid.iso
packer build -var "iso_path=$ISO" -var "iso_checksum=sha256:$(sha256sum $ISO | awk '{print $1}')" .
